# Інформаційна система «Аптека»

Навчальний консольний проєкт C# (.NET 8) за завданням №19 «Аптека».

## Можливості

- зберігання довідників аптек, товарів і постачальників у текстових файлах;
- зберігання кількості товару в кожній аптеці та терміну придатності;
- зберігання пропозицій постачальників, доступної кількості та переваги (1, 2 або 3);
- фасування товару у вигляді масиву;
- LINQ-запити з `join`, `where`, `orderby`, `Any`, `Sum`;
- перегляд залишків, прострочених товарів, пропозицій постачальників і сумарної вартості;
- пошук постачальників за назвою товару або фасуванням;
- додавання та видалення товару з аптеки;
- автоматичне збереження змін у текстових файлах.

## Структура проєкту

- `Program.cs` — меню, зчитування/запис файлів і LINQ-запити.
- `Models.cs` — класи `Pharmacy`, `Product`, `Supplier`, `PharmacyStock`, `SupplierOffer`.
- `Data/` — початкові дані для запуску.

Зв'язки між довідниками винесені в окремі класи `PharmacyStock` та `SupplierOffer`. Це дає змогу зберігати кілька постачальників для одного товару та вести окремі залишки в різних аптеках.

## Запуск у Visual Studio

1. Відкрийте файл `Apteka.csproj` у Visual Studio 2022 або новішій версії.
2. Переконайтеся, що встановлено .NET 8 SDK.
3. Запустіть проєкт клавішею **F5** або **Ctrl+F5**.

## Запуск через термінал

У папці проєкту виконайте:

```bash
dotnet run
```

Під час першого запуску програма створює початкові файли, якщо вони відсутні. Дані розташовані в каталозі `Data` поруч із виконуваною програмою. Після додавання або видалення товару зміни зберігаються автоматично.

## Формат файлів

У файлах поля розділяються крапкою з комою. Масив фасувань у `products.txt` зберігається через символ `|`. Дробова частина ціни у файлі записується через кому, відповідно до методичних рекомендацій.
